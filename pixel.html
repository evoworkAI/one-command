Prompt · 复制即用

像素环游世界视频
一站式提示词

把下面两段话复制给 AI，它就会做一个能玩的像素风旅行短片：角色走进每个地标、遇到宝可梦、弹出选项、你点一下、特效炸开。你只需要准备主题和几张图。

成品：单个 HTML 文件，双击就能看 产出时长：约 1 小时 无需编程基础

先想清楚这三件事

提示词里留了空，你填完再发。想不清楚也没关系，先按示例填着，AI 会跟着你的方向走。

  • 01

    主题是什么

    环游世界？打卡某座城市？公司产品巡礼？决定后面所有内容的走向。
  • 02

    四个地标

    每个地标要有一个辨识度极高的建筑，让 AI 生图时不会画歪。比如北京用大裤衩、纽约用自由女神。
  • 03

    在每个地标做什么

    这是片子的灵魂。别写"参观景点"，写具体的动作：吃烤鸭、喝豆汁、看日出。越具体越好笑。

第一段：让 AI 搭好骨架

先把这段发出去。它会让 AI 确认需求、列出还需要你提供什么，不会直接动手。

Prompt 1 / 需求确认 
我想做一个"像素风游戏"互动网页，模仿 GBA 宝可梦的横版画面。

【主题】宝可梦·环游世界

【四个地点】
1. 北京 —— 大裤衩（CCTV总部大楼）
2. 纽约 —— 自由女神像
3. 巴黎 —— 埃菲尔铁塔
4. 东京 —— 富士山

【每个地点的流程】
玩家角色从左边走进场景 → 弹出感叹号 → 白闪过渡 →
一只宝可梦从右上角落下 → 左上角出现名字牌和血条 →
屏幕下方出现对话文字 → 右下角弹出四个选项 →
玩家点选一个 → 攻击特效炸开 + 画面震动 → 过渡到下一个地点

【每个地点的四个选项】（每个都很具体，不要写成"参观景点"）
北京：拍大裤衩 / 吃烤鸭 / 喝豆汁 / 看日出
纽约：拍女神 / 吃热狗 / 打黄的 / 逛中央公园
巴黎：看铁塔 / 喝咖啡 / 买面包 / 游塞纳河
东京：爬富士山 / 吃拉面 / 泡温泉 / 看樱花

【开头和结尾】
开头：一张像素风拼贴图，四个地标并排，一个"开始旅程"按钮
结尾：通关字幕"旅程圆满完成"，然后一张结尾图 + "再来一次"按钮

【其他要求】
- 全程自动循环播放，播完回到开头
- 右上角有静音开关
- 有 8bit 游戏音效：遭遇、选择、攻击、收集
- 有背景音乐，循环播放
- 充分利用当前系统里已经安装的 skill 和能力来完成
- 宝可梦素材用 pokeapi 获取官方精灵图，不要重画
- 还需要的其他素材，用已配置的绘图 API 绘制

请先不要写代码。告诉我：
1. 你理解的需求对不对
2. 我需要提供哪些素材，每样素材的尺寸和格式要求
3. 用什么工具生成这些素材，给我可用的生图提示词
4. 还有哪些细节我没有考虑到，需要我补充
关键点：最后那句"请先不要写代码"很重要。先让 AI 把素材清单列清楚，你才知道要准备什么，避免它自己乱画背景。

第二段：素材齐了，让它开工

按 AI 给的清单准备好图片和音乐，全部放进一个文件夹，然后把文件名连同这段一起发出去。

Prompt 2 / 开始制作 
素材已备好，放在 [你的文件夹路径]：

- 四张背景图：01beijing.png / 02usa.png / 03paris.png / 04japan.png
- 角色走路帧：a01.png ~ a07.png
- 开场图：start.png
- 结尾图：final.png
- 背景音乐：musicbg.mp3

现在开始制作，要求：

【技术】
- 输出单个 HTML 文件，所有素材用 Base64 内嵌，不依赖任何外部文件
- 横版 4:3 舞台，宽 720px 高 540px，居中显示
- 不用任何外部库，纯原生 HTML + CSS + JavaScript

【画面】
- 背景图等比缩放到高度 540px，角色走动时背景缓慢向左滚动
- 主角用 a01~a07 七帧轮播做走路动画，每帧停 120 毫秒
- 宝可梦精灵图用 PokéAPI gen3 的官方素材，尺寸放大到 288px

【音效】
- 用 Web Audio API 现场合成 8bit 音效，不要依赖音频文件
- 遭遇、选择、攻击、收集 各一个音效
- 背景音乐用 musicbg.mp3 循环播放
- 右上角加静音开关
- 注意：浏览器要求用户先点击一次才能播放声音，要处理好

【交互】
- 开场"开始旅程"按钮可点击
- 四个选项都能点击，鼠标悬停有反馈
- 玩家不点的话，3 秒后自动选默认项
- 结尾"再来一次"按钮点击后重新开始

做完之后自己检查一遍，把可能有问题的地方告诉我。

之后是来回调整

第一版一定不会完美。这很正常，做这个项目我调了十几轮。下面是最常遇到的几类问题，直接对着描述就行。

位置问题

元素跑到画面外面了

"主角现在完全看不见，你查一下层级和定位。""攻击特效的中心点应该在宝可梦身上，不是画面中央。"

尺寸问题

某个东西太大或太小

直接说倍数："怪物放大 3 倍""选项框和文字等比例放大 1.5 倍"。说倍数比说像素好懂，AI 也能算准。

节奏问题

太快或太慢

"背景滚动慢一点，现在能看出重复了""走路时间从 2.4 秒改成 3 秒"。

氛围问题

不够爽

"攻击效果华丽一点，现在只有一个很小的飞溅。""打中的时候怪物、对话框、背景都要震一下。"

提问题的小技巧：说清楚"你改了什么"和"我看到了什么"。比如"你刚改了按钮居中，现在它歪到左边了"，比"按钮不对"有用得多。如果改坏了，直接说"改回上一次"，AI 会撤回。

想让片子更长或更短

  • 01

    加地点

    把新地标、宝可梦、四个选项按同样格式加进列表，再让它重新生成。代码是数据驱动的，加一个地点很便宜。
  • 02

    换主题

    把"环游世界"换成"我的履历"就是个人简历短片；换成"公司产品线"就是产品宣传片。结构完全一样。
  • 03

    做成竖版发抖音

    让它把舞台改成 405×720（9:16），元素位置重新排一遍。横版和竖版不能直接缩放，布局要重做。
  • 04

    导出成视频文件

    网页是能互动的，但发到平台需要 mp4。让它用 Playwright 录屏，或者直接用系统录屏软件录一遍。
