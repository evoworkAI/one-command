請幫我製作一個炫酷的動態簡歷展示網頁（單個 HTML 文件）。

【技術要求】
- 全屏背景使用 WebGL Ray Marching 體積光線效果（Prismatic Burst 風格）
  核心：44步體積光線行進，GPU逐像素計算，mat3旋轉+有機扭曲
- 鼠標移動時顯示流體動力學特效（Navier-Stokes 流體模擬）
  鼠標移動產生彩色流體漩渦，點擊噴射更強烈的流體
- GSAP 文字動畫：所有字母用純 2D 動畫（y + scale + opacity）
  不要用 rotationX，不要用 CSS 3D transform
- 每個場景用 display:none / display:flex 控制，確保場景之間絕對不疊加
- 全部寫在一個 HTML 文件，不依賴外部資源（字體除外）

【頁面結構】
開場：全黑啟動畫面，中間「▶ START」按鈕，點擊後：
  1. 啟動畫面淡出消失
  2. WebGL 背景光效開始
  3. 流體鼠標特效激活
  4. 如果提供了 BGM 文件名，同時播放背景音樂
  5. 按順序自動播放以下場景

第三步：操作流程

01
替換信息
把提示詞裡「我的信息」部分的藍色示例值，逐條替換成你自己的簡歷數據。每條一行，格式保持不變。
02
發給 Claude
把整段提示詞複製到 Claude 的對話框發送。Claude 會輸出一段完整的 HTML 代碼。
03
保存為 HTML 文件
把 Claude 輸出的代碼全部複製，新建一個文本文件，粘貼進去，保存為 resume.html。
04
（可選）放入 BGM
把你的背景音樂 .mp3 文件和 resume.html 放在同一個文件夾裡，文件名要和提示詞裡填的一致。
05
瀏覽器打開
雙擊 resume.html，用 Chrome 或 Safari 打開。點擊中間的「▶ START」按鈕，動畫和音樂同時開始。

注意事項

瀏覽器必須支持 WebGL（Chrome、Safari、Edge 均可）。移動端效果正常，但流體特效性能較高，建議桌面端展示。
音樂只能在點擊「START」按鈕後播放，瀏覽器不允許頁面自動播放聲音，這是正常的。
如果 Claude 輸出的效果不對（場景疊加、文字壓扁），直接說「場景有重疊，請修復」或「文字被壓扁了」，Claude 會定位問題修復。

常見問題

Q
可以改顏色風格嗎？
可以。在提示詞最後補充一句，例如「強調色改為紫色，數字全部用金色」，Claude 會按你的要求調整。
Q
可以添加更多場景嗎？
可以。在「場景時序」部分補充新場景的時間和內容描述，比如「加一個工作經歷場景，在項目之後」。
Q
如何導出為視頻文件？
這份提示詞輸出的是網頁版，可以直接錄屏。如果需要自動渲染成 MP4，需要另外用 HyperFrames 工具，那個流程更複雜。
Q
繁體中文還是簡體中文？
默認跟你輸入的語言走。如果你在信息裡用繁體，輸出就是繁體；想指定的話在提示詞最後加「文字全部用繁體中文」。
